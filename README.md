# ObstetraScroll

Medical education app with scrollable clinical content and video-based quiz reels. SvelteKit + FastAPI monorepo with MLX-powered pipeline.

## Stack

SvelteKit, FastAPI, pnpm + uv monorepo, Docker, Playwright, Biome.

## Development

```bash
pnpm install
pnpm run dev
```

## Docker

```bash
docker compose up
```

## Test

```bash
pnpm run test
pnpm exec playwright test
```
