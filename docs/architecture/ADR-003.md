# ADR-003: Quality Gates

**Status:** Accepted  
**Date:** 2026-05-17  
**Deciders:** Architecture Team  

## Context

We need automated quality gates that run on every PR and merge to `main`. The project uses a self-hosted macOS runner for some jobs and GitHub-hosted runners for others.

## Decision

### PR Gate (`pr-gate.yml`)

Runs on every pull request. Jobs:

| Job | Runner | Tool |
|-----|--------|------|
| Repo Hygiene | ubuntu-latest | Custom script (iCloud conflict check) |
| Node Quality | ubuntu-latest | `biome check`, `svelte-check`, `vitest --coverage`, `vite build` |
| Dependency Scan | ubuntu-latest | Trivy filesystem (HIGH/CRITICAL) |
| Secret Scanning | ubuntu-latest | Gitleaks |
| Infra Validation | ubuntu-latest | Dockerfile/compose checks, PostHog region check |
| Mutation Testing | ubuntu-latest | Stryker (incremental mode) |
| Repo Structure | ubuntu-latest | Custom Go tool `structurelint` built from source |
| Required Checks (PR) | ubuntu-latest | Aggregator — fails if any above fails |

### Merge Gate (`merge-gate.yml`)

Runs on push to `main`/`master`. Same as PR Gate plus:

| Job | Runner | Tool |
|-----|--------|------|
| CodeQL Security | ubuntu-latest | GitHub CodeQL (javascript-typescript) |

### PR Agent (`pr-agent.yml`)

- Trigger: issue_comment (created, edited) — slash-command only
- Runner: self-hosted (macOS)
- Model: `openai/glm-5.1` via [crof.ai](https://crof.ai) API
- Commands: `/review`, `/describe`, `/improve`, `/ask`
- Python venv managed at `/tmp/pr-agent-venv-py313`
- No auto-review. Manual invocation only.

### Mutation Test (Full) (`mutation-test.yml`)

- Runs on push to `main`/`master` (not on every PR)
- Full Stryker run with `--incremental --force`
- Caches incremental results between runs

### Branch Protection

- Required status check: `Required Checks (PR)` on main branch
- PR review required (1 approving review)
- Strict status check enforcement

## Consequences

- **Positive:** Comprehensive CI catches issues at multiple levels (style, type, test, security, infra).
- **Positive:** Mutation testing ensures test quality, not just coverage numbers.
- **Trade-off:** ~15min PR gate. Stryker incremental mode keeps it manageable.
- **Trade-off:** Self-hosted macOS runner required for PR-Agent. Falls back to CodeRabbit if unavailable.
